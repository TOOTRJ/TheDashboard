# Independent original-v2 SQL contract laboratory

PAPER-COMPACT-03B3C2B2B starts with a distinct private original-v2 configuration
and locked dependency boundary. These are guarded offline research artifacts,
not Supabase migrations, runtime credentials, production admission or restoration.
The original v1 SQL functions, model/transport formats and prior evidence remain
unchanged. No v2 field is stripped, rewritten or relabeled for a v1 validator.

`db-contract/research/portable_configuration.sql` freezes the complete tagged
original-v2 configuration template. Exact JSONB equality retains integer tags,
booleans, list order and every pinned model/code/lifecycle/assessment/mutation
policy field. Only the eight original documented string settings vary. Independent
checks require canonical decimal cash/rates, eight fully funded accounts with a
minimum one-dollar seed, uint64 decimal search seed, lowercase UUID source epoch,
1…10000 integer-string account-loss basis points and fees/adverse impact below
10000 basis points. A correctly rehashed `False` for the pinned lifespan integer
zero is rejected before reconstruction. Missing/extra policy fields are refused.

`portable_locked_checkpoint.sql` resolves the exact original-v2 command,
checkpoint and component headers in a separate `vn_portable_dependency_research`
namespace. Thirteen unique typed slots include eight genomes plus configuration,
optimizer, cohort, stable generation-zero source bars and EMA evidence. Scope,
member order, generations and immutable configuration references are checked.
The original request digest and resolved prior/following canonical UTF-8 wires
are returned. The resolver acquires the run lock before reading the prior, then
locks retained components in sorted digest order until transaction end. Supplied
following components cannot repair a missing retained prior dependency.

Original budgets remain: 65536 manifest bytes, 196608 ordinary request/component
bytes and 262144 resolved/aggregate dependency/Stop-reserve bytes. The last bigint
revision is reserved for the Stop shape; this partial shape check is explicitly
not Stop semantic admission. Successful and rejected calls change no rows. Only
the resolver capability can be granted to an offline auditor; every helper/table
and the trusted template remain private, all search paths are `pg_catalog`, and
the limited installer is neither superuser nor role/database creator.

Twenty actual owned PostgreSQL17.6 cases pass with zero skips (122.013 seconds
on the existing local arm64 fixture). The corpus explicitly uses two windows,
35 original-v2 commands and two replacements. Cases cover original byte-for-byte
expansion, rehashed TYPE1 substitutions, policy/version refusal, settings/ranges,
scope/slot/hash/prior failures, missing dependencies, unchanged row snapshots,
late run-lock and repeatable-read conflicts, retained-row locking, exact held-
position data-free Stop and privilege denial. No image was pulled or retagged;
the harness uses a UUID ownership label, network-none and only its own cleanup.

Every partial result explicitly reports false full-semantic, native-admission
and restoration authority. The deliberately accepted invalid money/source/history
boundary case documents that this resolver alone cannot accept trading state.
Full causal, economics, assessment, RNG/selection/actual child mutation and
server-owned same-version accepted-prior proof must compose next. Native
journal/projection/final source/lease proof, decoder/restoration, dependency-safe
retention, UI compatibility and bounded closed hosting remain later gates.
