## Version boundaries and implementation

The new operator is `ema-period-triangular-integer-v1`. The profile/code/model,
lifecycle/assessment, component/checkpoint and compact-command headers explicitly
select the new portable research version2. Its full mutation policy binds the
two domains, radii, exact mating rates,53-bit integer decision, step/clamp behavior,
fixed asset/no mutation draw, epoch/event limits and rejection/word budgets.
Configuration reconstruction requires the complete pinned dictionary; an unknown
or missing field/policy cannot quietly select a different operator.

The old provider model, base checkpoint and stable-partition source files are unchanged. The new model
and checkpoint adapters are reviewed version forks of the PR96 implementations, retaining
the same economics, source provenance, causal/risk/lifecycle/assessment behavior,
stable thirteen-slot candle/EMA partition,
fanout, original-wire replay, capture checks and Stop capacity. Their intentional
differences are the explicit headers, pinned mutation policy, operator selection,
strategy-counter increment bounds and new kernel binding. This avoids mutable shared globals or runtime monkeypatches
between versions. The [legacy baseline](research/legacy-ga-portable-integration-baseline.json)
records the original source hashes and70 full-candidate/compact-wire hash pairs
before integration.

The shared GA's default call still executes the existing Gaussian path. A plain
explicit operator version is required to enter the new branch; ordinary import
does not load the portable operator. Unknown selectors, incompatible profile,
asset/domain/rate/strength/counter settings and incomplete cohorts fail. The new
model keeps the same eight founders, common windows, stable tournament ties,
crossover and strategy-RNG draw order. Integer mutation uses the existing separate
per-child namespaces and records its operator in selection metadata. Fixed
controls and SOL/USD remain unchanged; offspring parentage matches actual mating.

The existing Genome representation stores integer-valued periods as floats.
At the operator boundary they must have an exact integral ratio; fractional,
boolean and nonfinite values are rejected, never rounded into validity. Mutation
then uses plain integers and the usual validated Genome representation. The
separate [mutation research](NATIVE-MUTATION-PORTABILITY.md) documents why the
Gaussian distribution/draw consumption cannot be relabeled as this operator.
