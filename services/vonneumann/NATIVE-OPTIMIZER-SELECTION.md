composes existing economics/source/causal/risk/assessment checks, then checks:

  The flat graph representation contains references; it constructs no Python

- Complete cohort genome/evaluation/result and evaluation-ID mirrors, plus
  insertion order. Displayed results use original-member order; the private
  evaluation map derives chronological terminal insertion, followed by missing
  records on interruption. They are deliberately different orders when needed.
- Exact fixed controls and two integer genes: EMA fast 3–12, slow 15–60, SOL/USD,
  quarter-cash sizing, 3% stop and 7% take profit. Founders derive from each
  independent gen0 seed; ordinary commands cannot change genotype/name; restart

  strategy RNG/counter without telling interrupted evaluations.
- Namespaced SHA256 integer seeding and all 624 MT19937 words/index, including
  seeding/twist/tempering, 53-bit random values, rejection-based integer sampling,
  pool sampling and fixed-asset draw consumption. No database `random()` or
  ambient Python/global RNG is used. Strategy continuation must match exactly.
- Tournament winners from the validated completed cohort and exact binary64
  fitness. Ties keep the first sampled candidate. Mate pools exclude the primary
  parent; the sexual draw, two crossover draws and both one-asset samples consume
  the strategy stream in actual order. Mutation uses separate per-child streams.
- Full selection metadata and birth lineage, including operation, original
  iteration, ordinal, version, source roles/order/IDs, child and distribution
  fields, parent IDs, complete selection bindings/context and name allocations.

Graph limits are narrower than the general encoder's limits because this is the
fixed eight-member GA subset: 24 levels, 256 compound nodes, 4096 visits, bounded

## Primary-source research and next decisions

The pinned CPython integer-seed convention partitions the magnitude into 32-bit
words. MT state includes 624 words and an index; `random()` combines two words
into 53 bits. The independent SQL uses integer equations and matches complete
state vectors, not merely a common seed. [Pinned CPython C source](https://github.com/python/cpython/blob/v3.12.14/Modules/_randommodule.c).

The pinned Python small-pool sampling path uses rejection to choose an index,
then removes the selected pool item; sampling a singleton still consumes words.
Gaussian generation caches its second variate and uses platform log/trigonometry/
square-root functions. Both gene mutation decisions can therefore share one
Gaussian pair. [Pinned Python implementation](https://github.com/python/cpython/blob/v3.12.14/Lib/random.py).
Python's documented reproducibility promise does not freeze every high-level
algorithm across versions. [Reproducibility notes](https://docs.python.org/3.12/library/random.html#notes-on-reproducibility).
