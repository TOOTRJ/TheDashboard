## Undo and stop rules

- **Before commit:** discard only the worker's own staged change. If a pointer was cleared, restore only its verified preimage if supported and necessary. Pinned `migrate undo` restores all pointers in the snapshot after checking the environment ID. Use it only with an exact one-service snapshot, a fresh matching state, and a reviewed inheritance and deployment scope. It does not undo an ownership claim or image change.
- **After IaC apply:** prefer a reviewed inverse against the current etag and the same service/ownership, restoring the recorded effective settings. If undo requires removing the ownership claim, explicitly dry-run release of only the verified service address, then use the exact preview/etag with existing environment-admin authority and reverify. Removing the declaration and applying it can delete the owned service. Ownership release does not restore settings or deployment. Do not reapply a released partial accidentally. [Railway ownership release semantics](https://docs.railway.com/cli/config#release-ownership).
- **After an unhealthy or uncertain deployment:** stop further applies, uploads and admission, observe the exact original result, and abort only the known in-progress candidate where appropriate. If eligible, use the verified closed rollback target; Railway rollback restores both its image and custom variables, and plan retention can remove that option. Never select an older provider/native credential-bearing deployment. If unavailable, use the prepared exact closed export with equivalent persisted configuration on the existing service. After December 1, restoring a legacy file is not a configuration rollback; use the inverse persisted settings and safe closed artifact instead. Confirm identity, mode, Auth/TLS and read-only health again. [Deployment rollback, retention and cancellation](https://docs.railway.com/deployments/deployment-actions#rollback).

Do not claim HOST-02C complete until the exact-source plan, applied settings, independent review, closed deployment checks and documented safe rollback agree.
